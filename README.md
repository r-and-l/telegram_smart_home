# Telegram Smart Home

Приложение для управления умным домом через Telegram, интегрированное с Home Assistant (AppDaemon).

## Архитектура

Приложение использует многослойную архитектуру для легкого масштабирования и разделения зон ответственности:

- `app.py`: Главный класс-точка входа (наследуется от `hass.Hass`), который инициализирует все подсистемы бота.
- `config.py`: Конфигурация устройств, меню и параметров мониторинга.
- `core/`: Ядро приложения
  - `telegram_api.py`: Обёртка над API Telegram для отправки, редактирования и удаления сообщений с отслеживанием `message_id`.
  - `router.py`: Маршрутизатор входящих событий (команды, коллбэки с кнопок) на основе таблицы префиксов.
  - `store.py`: Персистентное состояние в `state.json` (id сообщений, активные уведомления, пользовательские таймеры).
  - `devices.py`: Индексы по `DEVICES` — поиск устройства по сущности и по типу без линейных проходов.
- `services/`: Бизнес-логика
  - `menu_manager.py`: Логика состояний меню, их отрисовка и фоновое авто-обновление (например, тики таймера света).
  - `light_monitor.py`: Мониторинг забытого света, индивидуальные/групповые уведомления, таймеры и их сверка с реальным состоянием.
  - `automations.py`: Высокоуровневые автоматизации (например, ночной режим).
- `ui/`: Слой представления
  - `views.py`: Генерация текста и нативных таблиц Telegram (rich blocks) с текстовым fallback.
  - `keyboards.py`: Определение инлайн-клавиатур.
  - `translations.py`: Русские названия режимов кондиционера, скоростей вентилятора, погоды и фаз луны.
- `tests/`: Тесты логики уведомлений и таймеров на заглушках AppDaemon и Telegram.

## Таймеры забытого света

Значение по умолчанию задаётся полем `timer_minutes` у устройства в `config.py`.
Из Telegram таймеры настраиваются кнопкой **⏱ Таймеры** в главном меню: там видно
текущее значение по каждой комнате, а на экране комнаты доступны шаги из
`TIMER_CONFIG["steps"]`, пресеты, отключение уведомлений и возврат к значению из
`config.py`. Переопределения сохраняются в `state.json` и переживают перезапуск.

Уведомления тоже хранятся в `state.json`, а `LightMonitor.reconcile()` раз в
`LIGHT_MONITOR_CONFIG["reconcile_interval"]` секунд сверяет их с реальным состоянием
света. Поэтому уведомление удаляется даже если свет выключили выключателем, а бот
в этот момент перезагружался или Telegram не принял удаление с первой попытки.

## Добавление нового меню или устройств

В новой архитектуре нет необходимости создавать новые классы для каждого меню. Вся отрисовка строится динамически. 
Чтобы добавить новое устройство или категорию, достаточно внести изменения в `config.py`.

1. **Добавление категории меню:**
Добавьте раздел в словарь `CATEGORIES` внутри `config.py`:
```python
CATEGORIES = {
    ...
    "doors": {
        "title": "🚪 *Двери*\n\n",
        "button_label": "🚪 Двери",
    }
}
```
*Кнопка автоматически появится в главном меню.*

2. **Добавление устройства:**
Добавьте устройство в список `DEVICES` в `config.py`:
```python
DEVICES = [
    ...
    {
        "name": "Входная дверь",
        "entity": "lock.front_door",
        "type": "doors",
        "room": "hallway"
    }
]
```

## Установка и запуск

Приложение запускается как скрипт в AppDaemon для Home Assistant. Убедитесь, что настроены права доступа к сервисам `telegram_bot`.
