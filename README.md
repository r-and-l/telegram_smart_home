# Telegram Smart Home

Приложение для управления умным домом через Telegram, интегрированное с Home Assistant (AppDaemon).

## Архитектура

Приложение использует многослойную архитектуру для легкого масштабирования и разделения зон ответственности:

- `app.py`: Главный класс-точка входа (наследуется от `hass.Hass`), который инициализирует все подсистемы бота.
- `config.py`: Конфигурация устройств, меню и параметров мониторинга.
- `core/`: Ядро приложения
  - `telegram_api.py`: Обёртка над API Telegram для отправки и редактирования сообщений с отслеживанием `message_id`.
  - `router.py`: Маршрутизатор входящих событий (команды, коллбэки с кнопок).
- `services/`: Бизнес-логика
  - `menu_manager.py`: Логика состояний меню, их отрисовка и фоновое авто-обновление (например, тики таймера света).
  - `light_monitor.py`: Фоновый мониторинг состояния освещения и отправка индивидуальных/групповых уведомлений при забытом свете.
  - `automations.py`: Высокоуровневые автоматизации (например, ночной режим).
- `ui/`: Слой представления
  - `views.py`: Генерация текста, форматирование меню в виде Markdown-таблиц (с использованием `PrettyTable`).
  - `keyboards.py`: Определение инлайн-клавиатур.

## Добавление нового меню или устройств

В новой архитектуре нет необходимости создавать новые классы для каждого меню. Вся отрисовка строится динамически. 
Чтобы добавить новое устройство или категорию, достаточно внести изменения в `config.py`.

1. **Добавление категории меню:**
Добавьте раздел в словарь `CATEGORIES` внутри `config.py`:
```python
CATEGORIES = {
    ...
    "doors": {
        "title": "🚪 *Двери*\n\n",
        "button_label": "🚪 Двери",
    }
}
```
*Кнопка автоматически появится в главном меню.*

2. **Добавление устройства:**
Добавьте устройство в список `DEVICES` в `config.py`:
```python
DEVICES = [
    ...
    {
        "name": "Входная дверь",
        "entity": "lock.front_door",
        "type": "doors",
        "room": "hallway"
    }
]
```

## Установка и запуск

Приложение запускается как скрипт в AppDaemon для Home Assistant. Убедитесь, что настроены права доступа к сервисам `telegram_bot`.
